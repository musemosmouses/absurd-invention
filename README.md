One-sentence absurd invention pitch for the [One-Sentence Absurd Invention Pitch](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a) bounty on make.fun — a ridiculous invention that fixes a tiny everyday annoyance.

> A TV remote with separation anxiety that beeps louder the deeper it slides between the sofa cushions until it tearfully confesses exactly where it is hiding.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```

Requires Node 22.18 or later. Deterministic: no network, no clock, no randomness. The program validates the entry (1–220 characters, exactly one sentence) and writes it to `entry.txt` in the output directory.
